# ERP Apollo Cyntra

Aplicación web ERP para Apollo Cyntra (`erp.apollocyntra.app`).

## Despliegue

1. Ejecuta la tarea de VS Code **🚀 Deploy a servidor**, o lanza `./deploy.sh` desde la terminal.
2. El script pide un mensaje de commit, sube los cambios a GitHub y actualiza el servidor con `git reset --hard origin/main`.
